# Автоматизированные тесты для web-приложения
Этот проект содержит автоматизированные тесты для сервиса "Яндекс.Самокат".


## Описание
В данном проекте реализованы тесты функциональности веб-приложения. Основные тесты включают проверку основных компанентов, таких как оформление заказа, переходы между старницами, выпадающий список в разделе «Вопросы о важном».


## Предпосылки
Перед началом работы убедитесь, что у вас установлены:

- Python 
- Браузер Mozilla Firefox и FirefoxDriver
